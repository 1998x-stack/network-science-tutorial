和朋友连接，不代表一定采取相同策略

网络给出谁与谁发生互动，但并不规定谁会合作、模仿或改变意见。想理解群体合作，还需要定义每个人可选的策略、一次互动带来什么收益，以及谁在什么时候更新策略。把这三个层次分开，才能看清“邻居多是否占优势”“桥梁是否促进合作”等问题是否有意义。

先定义边上的收益：捐赠博弈

令每位节点选择 C（合作）或 D（不合作），记 sᵢ=1 表示合作，否则为 0。每位合作节点对每个邻居付出成本 c，同时使那位邻居得到收益 b；不合作节点既不支付成本，也不给邻居带来收益。这里 b=3、c=1，且收益在每条无向边的两个方向累加。

B 的合作成本更高，因为 B 有两条边，需要给两个邻居各支付一份成本。C 虽然自己不合作，仍从 B 的合作获得收益。这正是社交困境结构：单轮个人收益未必直接奖励无条件合作。

收益与策略是两件独立的事

b=3.0，c=1；当前策略始终为 C、C、D、D。改变收益参数并不会自动更新策略。

若在某种演化博弈中，让更高收益的邻居更可能被模仿，还必须额外指定模仿概率、更新顺序与随机选择机制。仅凭某轮中 C 的分数最高，并不能推断所有节点下一轮必将改为不合作。

Voter 模型：中性模仿，不以收益为依据

Voter（选民/意见复制）模型的一个常见异步版本，在每次更新中随机选中一个节点，再随机选中它的一个邻居，将该节点的状态改为邻居当前状态。它不根据捐赠博弈收益决定是否复制，且一次只更新一个节点。本图中若指定 B 复制 C，B 的状态由合作变成不合作；其他三个节点在这一步不变。

图中的原始四节点策略仅是更新前的快照。该组件展示两种可能的条件分支，并不表示先复制 A 再复制 C 的连续随机轨迹。若要预测全局共识，需要在选定的随机更新规则下重复仿真，并固定种子。

为什么经典的合作判据有很强的条件？

Ohtsuki 等人在弱选择、特定规则图与指定更新机制的模型下，给出过形如 b/c>k 的合作优势条件，其中 k 表示规则图的邻居数。这个条件不是所有图、所有更新规则、所有游戏的普遍定律。比如本章四节点路径不是 k-规则图，因此不应直接套用这个判据。

在“死亡—出生”更新、出生—死亡更新、模仿更新、同步选择和异步选择之间，实际的群体动力学可能不同。结论必须同时注明收益函数、策略更新规则、选取概率、图结构与初始状态。

连续意见：有界信任不等于二值投票

有界信任模型让每个人持有连续意见 xᵢ，例如在 [0,1] 内。Hegselmann–Krause 的一种同步版本只平均与自己意见距离不超过 ε 的个体（包括自己）：

xi(t+1)=1|Ci(t)|∑j∈Ci(t)xj(t)

对完全相互可见的三人，初始意见为 0.1、0.2、0.9，ε=0.2 时，前两位彼此相差 0.1，下一轮各成为 0.15；第三位与前两位距离都超过 ε，继续保持 0.9。这不是捐赠博弈，也不等价于 Voter 的随机复制；三类模型使用不同的状态空间。

代码：先复算收益，再独立验证一次 Voter 更新

运行环境：Python 3.11+、NetworkX 3.3+。使用无向路径、确定性初始状态和明确的复制对象，没有模拟任何未经声明的随机平衡态。

import networkx as nx

g = nx.path_graph(["A", "B", "C", "D"])
strategy = {"A": 1, "B": 1, "C": 0, "D": 0}
b, cost = 3, 1

def payoffs(states):
    return {v: b * sum(states[u] for u in g.neighbors(v))
                 - cost * g.degree(v) * states[v] for v in g}

assert [payoffs(strategy)[v] for v in "ABCD"] == [2, 1, 3, 0]
after = dict(strategy)
after["B"] = strategy["C"]  # one asynchronous voter copy
assert [after[v] for v in "ABCD"] == [1, 0, 0, 0]

opinions = [0.1, 0.2, 0.9]
epsilon = 0.2
updated = [sum(y for y in opinions if abs(y-x) <= epsilon)
           / sum(abs(y-x) <= epsilon for y in opinions)
           for x in opinions]
assert all(abs(a-b) < 1e-12 for a,b in zip(updated, [0.15,0.15,0.9]))
print("payoffs:", payoffs(strategy), "voter copy:", after)

对现实合作行为的因果推断需要选择机制与个体异质性等独立证据；网络上一个可重复的模型结果只是理论机制的例证。

1. 网络科学的跨领域力量来自统一形式，不来自统一解释

网络结构 G=(V,E) 能描述蛋白、脑区、人员、论文、基础设施和量子设备，但节点和边永远需要独立定义。蛋白之间有物理互作证据，不等于一条必然导致疾病的因果链；脑区信号相关不必是直接解剖通路；社交平台用户共同观看某物品不自动说明好友影响；量子通信线路可达不意味着已经具备纠缠资源与足够保真度。每项研究应在引入图指标前记录观测过程、边的置信度、方向、权重、时间、采样策略和缺失机制。

2. 网络医学：候选疾病模块不等于临床因果证据

Barabási、Gulbahce 和 Loscalzo（2011）提出以网络视角研究复杂疾病，包括细胞互作结构、疾病相关模块与可能的药物靶点。假设 A、B、C 是三个有相互作用证据的蛋白，模块 S={A,B,C} 与某疾病的研究结果相关。一个候选靶点 T 在互作图中距离模块很近，可被纳入验证优先级；但是边未必具有作用方向，网络中可能存在测量噪声和缺失节点，也没有自动得到剂量、安全性或临床效应。

可定义候选蛋白 v 到模块 S 的网络距离 d(v,S)=minₛ∈S shortest_path(v,s)，但高度数枢纽自然接近许多节点，因此需要度数匹配的随机基线与外部队列。若某些蛋白未被采集，路径长度可能完全改变；即使网络距离有显著预测价值，也仍需明确蛋白互作与疾病机制之间的推理链，不把图论路径误写为真实生化反应链。

3. 脑功能网络：换一个阈值，同一组信号就会变成另一张图

脑网络可以来自扩散 MRI 等结构连接测量，也可以由时间序列之间的相关或其他统计依赖构造功能连接。Bullmore 与 Sporns（2009）总结了不同测量层次的图论分析方法。功能相关的边不指定信息传递方向，也可能受全局信号、运动、预处理、脑区划分和观察窗口影响。

用合成三脑区 A、B、C 演示相关矩阵：|r_AB|=0.8、|r_BC|=0.6、|r_AC|=0.2。明示阈值规则：当 |r|≥τ 时保留无向边，节点集始终为 {A,B,C}。在 τ=0.5，保留 AB、BC，连通分量 1 个；在 τ=0.7，仅保留 AB，C 孤立，分量变成 2 个。这不是大脑结构随阈值真实断裂，而是研究者的图提取决策。

真实研究还要指定是否使用 Pearson 相关、偏相关、有效连接或其他指标，报告多重检验与阈值敏感性。展示一张漂亮的脑图，不能替代稳健性检验，更不能从某节点中心性高就直接推断个人智力、心理状态或诊断。

4. 计算社会科学：同质性、共同环境与社会影响的区分

设 X 是某个产品的曝光状态，Y 是是否采纳，Z 是背景风险（例如偏好与渠道等共同因素）。在合成的生成机制中只有 Z→X 和 Z→Y，没有 X→Y 的直接作用。但由于 Z 同时影响曝光构成与采纳率，汇总观察数据会产生貌似强烈的“影响效应”。

分层算数如下。Z=低风险时，曝光组 20 人中 2 人采纳（10%），未曝光组 80 人中 8 人采纳（10%）；Z=高风险时，曝光组 80 人中 32 人采纳（40%），未曝光组 20 人中 8 人采纳（40%）。各层内曝光与否的采纳率相同，但将两层合并后，曝光组为 34/100=34%，未曝光组为 16/100=16%，表观差为 18 个百分点。这只是在生成机制中的统计混杂，不能称为真实平台观察结果。

因果识别需要事先定义干预、调整混杂、理解时间顺序，考虑社交传播中个体之间的干扰。PC 等基于条件独立的因果结构学习方法也依赖马尔可夫性、忠实性、无未测混杂等假设，观测分布通常只能识别某个马尔可夫等价类；不能只因为算法画了有向箭头就视为确定的真实因果链。

5. 公平性：群体预测率相同不等于没有不公

图算法可能吸收节点标签、邻居分布、历史曝光机会与社会同质性形成的偏差。一种简单的输出统计是 demographic parity gap：不同群体的正预测率绝对差。如果组甲 4 人中 3 人预测为正、组乙 4 人中 1 人预测为正，则两组率分别 75% 和 25%，差 50 个百分点。这没有使用任何现实中的敏感人群信息。

这个指标不能单独告诉我们差异是数据质量、资格条件还是不公造成的，也不能替代均等机会（基于真实标签的 TPR/FPR）、个体公平或反事实公平。Kusner 等（NeurIPS 2017）的反事实公平要求明确的因果模型；仅通过调整分类阈值让两组通过率一致，不证明模型已满足反事实公平。

6. 量子网络与图基础模型：图连通不等于功能可实现

量子网络的边可能描述经典信道、量子信道或可分配的纠缠资源。经典图上 A 到 C 存在 A–B–C 路径，不保证量子态可以高保真地传输；还需明确量子存储、噪声、同步、纠缠交换和资源消耗。未经具体硬件实验与协议条件，不能假设一个图算法就获得量子通信优势。

图基础模型和网络跨域泛化也面临结构 OOD、数据采集偏差、节点/边类型迁移、新图冷启动、隐私和解释可信度挑战。论文若只在固定随机切分的同一张图上取得较好链接预测指标，不代表能面对新时间、新平台或新医学实验可靠泛化。原文证据和新研究猜想要明确分开。

7. 可复算程序：阈值、混杂、公平性逐条核对

下列 Python 标准库代码不接触真实医疗、脑影像或人群数据，分别验证本章三个小例子。一个断言对应一个明确的数学定义，代码结果不是研究论文复现。

from math import isclose

weights = {("A", "B"): .8, ("B", "C"): .6, ("A", "C"): .2}

def threshold_graph(tau):
    edges = [(a, b) for (a, b), w in weights.items()
             if w + 1e-12 >= tau]
    adj = {v: set() for v in "ABC"}
    for a, b in edges:
        adj[a].add(b)
        adj[b].add(a)
    visited = set()
    components = 0
    for node in adj:
        if node in visited:
            continue
        components += 1
        todo = [node]
        while todo:
            v = todo.pop()
            if v in visited:
                continue
            visited.add(v)
            todo.extend(adj[v] - visited)
    return len(edges), components

assert threshold_graph(.5) == (2, 1)
assert threshold_graph(.7) == (1, 2)
exposure_rate = (2 + 32) / (20 + 80)
control_rate = (8 + 8) / (80 + 20)
assert isclose(exposure_rate - control_rate, .18)
assert isclose(2/20 - 8/80, 0)
assert isclose(32/80 - 8/20, 0)
assert isclose(abs(3/4 - 1/4), .5)
print("brain edges/components:", threshold_graph(.7),
      "observational risk diff:", exposure_rate-control_rate)

真正的医学与政策研究还需外部数据验证、风险评估、伦理审查及适用场景的专业决策。这里的可复算性只保证人工设置的图和概率计算正确。

8. 面对“网络能够解释 X”的五步检查

先查节点和边如何观测；再问是否有阈值/采样/测量敏感性；然后区分结构与统计相关；再检查时间、混杂、干扰与候选因果模型；最后查是否有独立真实数据或干预证据。图是建立可检验假说的语言，不是免除实证验证的许可证。

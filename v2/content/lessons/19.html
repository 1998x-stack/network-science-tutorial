两个人在同一个网络里不相连，换个关系层却可能相连

现实系统经常包含多种不同的关系。同一批人可以在“朋友关系”层里连接，也可能在“项目合作”层里连接。把这两种关系全部并成一个无向图虽然简单，却无法再区分：两个人是朋友、同事，还是需要先从一种关系切换到另一种关系。

实体、层、节点—层对是不同的概念

现实实体为 A、B、C、D，总数为 4。若要记录每个实体在两个关系层中的状态，就使用节点—层对，例如 (A, 社交) 和 (A, 合作)。每个节点—层对是多层表示中的一个顶点，因而共有 4×2=8 个多层状态；它们并非现实中的 8 个人。

对象示例解释
实体（actor）A、B、C、D现实中 4 位参与者
层（layer）社交、合作两类不同关系
层内边社交 AB、BC；合作 AC、CD4 条独立按层定义的关系
层间耦合边(A,社交)–(A,合作) 等 4 条同一实体可跨层转换
节点—层状态4×2=8表示状态，不是新增真实参与者

Kivelä 等人用统一框架区分多层网络、multiplex、互依网络等相关概念。不同模型的层间耦合并不总是“同一实体跨层跳转”，有些互依系统的跨层关系代表“某个组件依赖另一组件存活”。必须在数据合同中明确语义。

为什么需要 supra-adjacency，而非直接做边的并集？

对齐 A、B、C、D 的节点顺序后，社交层的邻接矩阵记为 Aₛ，合作层记为 A꜀。如果同一实体在两个层之间可以一对一耦合，简单双层块矩阵可写成：

𝒜=(AsωIωIAc)

其中 I 是 4×4 单位矩阵，ω 是层间耦合的权重，而不是“跨层必然耗时 ω 秒”。若把 ω 用来表示连接强度，则它和最短路径成本应由研究者另行建立映射；本章的最短路径演示只把每条允许的层间转移看作一步，不把大权重当作更长距离。

对于当前示例，跨层连接允许时，整个 supra 图有 8 个节点—层状态、4 条层内边、4 条耦合边，共 8 条无向边。禁用层间转换时，两个层彼此独立，虽然节点副本名字相同，也不存在一条从社交层直接行走到合作层的路径。

从 B 的社交状态去到 D 的合作状态

把 B_social 作为起点，把 D_collab 作为目标。按每条边都是一步的拓扑路径，最短合法路线为：

(B, 社交) → (C, 社交) → (C, 合作) → (D, 合作)，一共 3 步，其中包含一次明确的层间切换。

若把两个层的边并成一张单层图，B–C–D 看起来只要 2 步，层间转换的成本与语义已经丢失。若根本不允许层间跳转，B_social 到 D_collab 在多层状态图中不可达。这三个答案看起来不一致，但它们实际上回答了三个不同模型的问题。

比较不同的层间转换假设

从 B 到 D 的最短步数3
层间转换次数1

多层路径：B_social → C_social → C_collab → D_collab，共 3 条边、1 次层间切换。

多层模型解决了什么，又额外引入什么？

在多种社交关系、交通模式换乘、电力与通信依赖等问题中，保留层标签能防止“同样是连接”却混淆机制；但多层网络还需要记录层间转换的可行性、代价、方向与失败影响。比如一条“电力节点依赖通信设备”的跨层边可能是依赖关系而不是可行走的路线，不能直接拿来做旅行路线。

本章这个 8 状态的 supra 图只是带有同实体耦合边的 multiplex 教学模型，并非对一般互依网络的完整实现。现实系统可能有不同节点集合、跨实体耦合、异步变化和更复杂的边类型。

代码：构建双层图，和扁平投影交叉对照

运行环境 Python 3.11+、NetworkX 3.3+。通过明确的层标识构建 8 个节点—层对，并逐一测试“可切换、不可切换、扁平化”三种设定。

import networkx as nx

actors = list("ABCD")
social = [("A","B"),("B","C")]
collab = [("A","C"),("C","D")]
supra = nx.Graph()
for layer in ("social","collab"):
    supra.add_nodes_from((v,layer) for v in actors)
for u,v in social:
    supra.add_edge((u,"social"),(v,"social"))
for u,v in collab:
    supra.add_edge((u,"collab"),(v,"collab"))
for v in actors:
    supra.add_edge((v,"social"),(v,"collab"))

start, goal = ("B","social"), ("D","collab")
assert (supra.number_of_nodes(),supra.number_of_edges()) == (8,8)
assert nx.shortest_path_length(supra,start,goal) == 3

blocked = supra.copy()
blocked.remove_edges_from([((v,"social"),(v,"collab")) for v in actors])
assert not nx.has_path(blocked,start,goal)

flat = nx.Graph(social+collab)
assert nx.shortest_path_length(flat,"B","D") == 2
print("supra path:", nx.shortest_path(supra,start,goal))

这验证的是规定的多层状态和拓扑步数；没有推断现实跨层换乘需要几分钟，也没有根据 ω 的数值自动计算旅行成本。

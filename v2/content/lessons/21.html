同一张图怎样转成可学习的节点向量？先看条件随机游走，再看训练目标、结构角色、时间外评估与局限。

核心问题：同一社团的成员与不同社团中角色相同的人，应该拥有同样的向量吗？

1. 从网络邻接关系到数值表示：目标必须先说清楚

给定图 G=(V,E)，节点可能是用户、论文、设备或蛋白质；一条边必须先定义清楚，例如“在观察窗内共同署名过论文”，不能直接把边解释成因果影响。节点嵌入就是构造映射 f:V→Rᵈ，把每个节点编码为 d 维向量，使该向量适合某项下游任务。向量的绝对坐标通常并无固定语义，两次训练的结果可能整体旋转；相对距离、内积和任务表现才有可比较的意义。

“相似”至少有三个不同定义：相邻或共同邻居多是局部接近性；在随机游走窗口中经常共现是上下文接近性；在两个彼此遥远的子图中扮演类似枢纽、叶子或桥梁角色，是结构角色相似性。三者不能直接划等号。设两个不同社团各有一个星形中心，它们即使完全不相连，也可能角色相似；但普通局部游走未必会让二者共现。

具体输出也必须说明：DeepWalk、node2vec 的经典浅层模型通常为已知节点分别学习一个向量表；若线上出现新用户，单凭已有向量表一般不能直接得到该用户的向量，必须额外设计算法、增量更新或使用能处理特征的归纳模型。嵌入维数 d 与训练样本数不同，d 较大并不自动提升泛化能力。

研究目标保留什么下游任务示例不能直接保证什么
局部邻近共同邻居、短路径链接预测真实好友关系形成的因果性
随机游走上下文多步访问的共现节点分类、检索跨分量结构等价
结构角色度序列或邻域形态相似职业/角色检索节点处于相同社团
端到端节点预测任务损失中的有效信息分类/回归跨时间漂移后仍有效

2. DeepWalk：把随机游走当成训练语料

DeepWalk（Perozzi 等，KDD 2014）将图上的短随机游走转成节点序列。对无权简单无向图，位于 v 时，下一步在 N(v) 中均匀选一个邻居；若 d(v)=0，游走立即终止。这个转移是 P(v→x)=1/d(v)，它与 PageRank 的传送项不同，也不等于“随机游走就是谱分解”。后者只有在特定矩阵分解分析与极限假设下才能建立联系，不能用来描述原始算法的直接步骤。

例如图上得到一条序列 A,B,C,B,D，窗口半径为 2，围绕中心 C 可收集上下文 A、B、B、D；B 的两次出现对应两个位置的训练事件。随机游走只是采样机制，不是节点向量；向量需要后续目标函数训练得到。

最直观的全量 Skip-gram 目标是最大化给定中心节点 u 时上下文节点 c 的条件概率。若用两张向量表（中心向量 z 和上下文向量 z′），则：

max∑(u,c)∈Dlogezu·zc′∑v∈Vezu·zv′

D 是由游走窗口形成的有序节点对多重集合。全量 softmax 每次可能需要遍历整个节点表，因此实际实现往往使用负采样或分层 softmax。负采样的每个正对 (u,c) 试图提高 σ(zᵤ·z′꜀)，同时降低噪声样本的对应内积；噪声分布、次数与窗口定义都要记录。负样本不是“图中尚不存在就一定永远为负”的因果标签。

3. node2vec：p 和 q 修改的是二阶转移概率

node2vec（Grover & Leskovec，KDD 2016）引入前一步访问节点 t。假设游走已经走过 t→v，下一步考虑候选 x∈N(v)，其未归一化转移权重与 αₚᵩ(t,x)·w(v,x) 成正比。无权图中，若 x=t，因子为 1/p；若 x 与 t 直接相邻，因子为 1；否则距离为 2，因子为 1/q。归一化分母是所有候选权重之和，不能只看某个 1/q 就宣称它是转移概率。

P(x|v,t)=αpq(t,x)·wvx∑y∈N(v)αpq(t,y)wvy

取 p=1、q=2，候选 A、C、D 权重为 1、1、1/2，总和 5/2，概率分别是 0.4、0.4、0.2。若把 q 改为 1/2，D 权重变成 2，总和 4，D 概率变成 1/2。q 较小通常鼓励从前一节点向外探索，q 较大鼓励局部游走，但这不是严格 DFS/BFS，也不能保证“DFS 必学到结构角色”。图的度、边权、分量与采样长度都会影响真实上下文。

交互实验：二阶转移的概率质量守恒

P(B→A | A,B)0.400
P(B→C | A,B)0.400
P(B→D | A,B)0.200

总概率 = 1.000；仅对应图中四节点玩具网络。

4. 同一社团 vs 相同角色：struc2vec 为何单独存在

假设两个互不连通的星形分量各有一个中心：中心都具有较高度数，并连接许多低度叶子。单纯邻近游走不能跨分量生成正例，因此可能学习不到“两个中心承担相同角色”。struc2vec（Ribeiro 等，KDD 2017）采用层级结构相似性建立新的多层辅助图，再在辅助图上生成结构上下文；这不是把原图节点编号送入 node2vec，也不是只比较“一跳度数是否相同”。

原论文使用不同邻域尺度的度序列等结构描述与距离比较，并围绕结构相似性构造跨分量的上下文机会。这会增加预处理与存储成本。它更适合角色相似研究，但结构角色仍然需要明确任务定义。若两个完全不同的组织中“度高”并不代表功能相同，那么该表征也不能自动给出功能解释。

方法用于生成上下文的信号优点必须承认的限制
DeepWalk无偏截断随机游走简单、自然的局部上下文窗口与访问偏差敏感
node2vec带上一节点条件的 p/q 有偏游走可调局部/向外探索并非严格 BFS/DFS；仍是有限样本
struc2vec跨节点结构相似性构成的多层上下文图能强调远距离结构角色计算昂贵，结构相似不等于业务同质
LINE一阶、二阶网络邻近目标适合大规模邻接建模与随机游走窗口目标不等价

5. 数据切分：嵌入本身也可能泄漏未来答案

做未来新边预测时，不能先用包含未来边的全图训练随机游走嵌入，再把那条未来边藏进测试标签。虽然分类模型训练时未看到测试标签，但图表示已经偷看了答案。应先按事件时间得到 G_train，只在这张训练图上构造游走、度、负例采样池和向量；再在明确的未来窗口评估。新节点、缺失关系和不可见候选应分别记录。

评估节点分类也要区分：Transductive 设定允许访问测试节点的无标签结构/特征，但不允许测试标签流入监督；Inductive 设定还可能要求测试节点或整张图都不可在训练阶段出现。两者结果不可直接比较。AUC、AP 与 Precision@k 的候选边构成、类别失衡和采样分布必须明确；用 t-SNE 降维看到两个团簇，不能作为准确率证明。

6. 不依赖训练包的可复算最小实验

下面使用 Python 标准库对四节点玩具图计算 node2vec 单步概率；检查权重和为 1、q 变化后的方向与孤立节点规则。它只核对采样机制，没有训练 Skip-gram、没有生成嵌入、没有复现 KDD 论文实验。

from math import isclose

def transition(p, q):
    if p <= 0 or q <= 0:
        raise ValueError("p and q must be positive")
    weights = {"A": 1.0 / p, "C": 1.0, "D": 1.0 / q}
    total = sum(weights.values())
    return {node: weight / total for node, weight in weights.items()}

base = transition(1.0, 2.0)
outward = transition(1.0, 0.5)
assert all(isclose(base[k], v) for k, v in {"A": .4, "C": .4, "D": .2}.items())
assert isclose(sum(base.values()), 1.0)
assert isclose(outward["D"], .5)
assert outward["D"] > base["D"]
print("node2vec transition:", base)

要实现完整 node2vec，还需对每条 (t,v) 边预处理或动态计算邻居权重、采样多条长度受控的游走、用固定随机数种子训练 Skip-gram、保留训练节点集合，并将表征输出关联到稳定的节点 ID。对有向图，候选的距离规则和采样语义应依实现版本另作约定，不套用本页无向玩具图。

7. 从这页可以迁移的研究流程

先定义节点是什么、边何时存在、要保留哪种相似性；再选游走规则与训练目标；最后按任务时间和候选集合检验模型。向量维数、p/q、负采样、节点频率、孤立点策略、评价指标都写进实验账本。不要以“看上去聚成两团”代替真正的外部验证，也不要把低维表示解释成可直接识别的社会身份。

研究级交叉验证：游走训练语料也必须严格隔离未来边

DeepWalk/node2vec 在学习向量之前需要访问图邻接。合成洁净图中 B 与 D 未相连，无偏一阶游走 P(B→D)=0；提前加入 BD@5 后，P(B→D)=1/3。这个 1/3 是无偏一阶游走概率，不是任意 p/q 的 node2vec 二阶条件概率。

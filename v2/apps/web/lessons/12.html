连成一片的网络，为什么传播结果仍可能截然不同？

一条连接不等于一次传播。网络的边只是潜在接触；传播是否发生，还需要感染状态、接触概率、恢复规则和时间顺序。即使所有节点最终都可达，传播也可能因概率不足或感染者提前康复而终止。本章先给出一条五节点路径上的清晰演算，再讨论随机图上的传播阈值。

区分状态与传播事件：SIR 和 SIS

SIR 的状态为 S（susceptible，易感）、I（infectious，可传播感染）、R（removed，移出传播状态）。在经典简化模型中，S 受到感染接触可成为 I，I 之后进入 R，R 不再回到 S；这里的 R 可以表示康复免疫或其他退出传播过程，不意味着所有现实疾病都有终生免疫。

SIS 中 I 康复后回到 S，因此同一节点未来可能再次感染。SIR 与 SIS 可以使用同一张图，但不同的恢复规则造成了不同的长期行为：SIR 的单轮疫情终会因为没有新的易感传播链而耗尽；SIS 在某些参数下可能持续反复。

SI、SIR、SIS 模型的转移与再感染规则对照
模型允许的转移是否可再次被感染典型问题
SIRS→I→R本模型中否一次疫情最终影响多少节点
SISS↔I是感染能否在网络中持续
本章路径实验同步 SIR，I 只持续一轮否逐轮检验状态更新顺序

两者都不是现实流行病学的完整模型：潜伏期、无症状感染、接触频次、人口流动与时间变化等，需要单独加入规则。

从每条独立接触边推导感染概率

设某个易感节点当前拥有 m 个已经感染、并在这一轮可以接触它的邻居。每条感染接触独立成功的概率均为 β，那么全部 m 条接触都失败的概率是 (1−β) 的 m 次方。因此：

P(S→I)=1−(1−β)m

这严格依赖“各接触在给定状态下独立、概率相同”的教学假设。现实的重复接触、家庭相关风险或共享环境可以破坏独立性。若 m=0，风险为 0；若 β=1 且 m≥1，风险为 1。

同时调整单边概率与暴露邻居数

m=2，β=0.30；至少一次成功的理论概率 = 51.00%。

把同步更新的时间顺序固定下来

令 t=0 时 A 感染，B–E 易感。每一轮先使用上一轮所有 I 节点计算邻居是否感染，然后才让旧 I 变成 R；刚刚感染的新 I 不会在同一轮继续传给下一位。因此当 β=1、传染期恰好一轮时，感染前沿每轮沿路径移动一个节点。

逐步查看五节点路径的 SIR 状态

S 易感4
I 感染1
R 移除0

t=0：A=I，B=S，C=S，D=S，E=S。

状态数量每轮保持 S+I+R=5。这是程序可以逐轮测试的守恒不变量。这里的“同步一轮”并不等价于真实时间一天或现实患者的感染期。

为什么“传播阈值”不是一个通用常数？

在大规模、局部近似树状且无度相关的配置模型网络上，若一次感染沿每条边传播的整个感染期可传递概率为 T，SIR 最终传播规模可借助键渗流的分枝因子理解：

T⟨k2⟩−⟨k⟩⟨k⟩>1

这里 T 是单条边在整个传染过程内实际传递成功的概率，并非任意情形都等于前面每轮的 β。该条件是模型在大图极限下出现巨规模传播分枝的判据，不适合直接用来预测五节点路径上会感染多少人。

另一方面，在经典无度相关网络的 SIS 异质平均场（HMF）近似中，传播率与恢复率之比 λ 的临界值形式为 ⟨k⟩/⟨k²⟩。它不是上面的 SIR 键渗流阈值。有限网络、度相关、时变接触及更精细的谱方法都可能给出不同数值；不能笼统声称“幂律网络的阈值永远等于零”。

可复现实验：一步感染期的同步 SIR

依赖 Python 3.11+、NetworkX 3.3+。固定路径、β=1、随机种子，先以旧状态决定新增感染，再更新康复。真实随机实验应扫不同 β 并重复多种随机种子，而不是用一条轨迹作统计推断。

import random
import networkx as nx

g = nx.path_graph(5)
rng = random.Random(7)
state = {v: ("I" if v == 0 else "S") for v in g}

def step(old, beta):
    new = dict(old)
    for v in sorted(g):
        if old[v] == "I":
            new[v] = "R"
        elif old[v] == "S":
            for u in sorted(g.neighbors(v)):
                if old[u] == "I" and rng.random() < beta:
                    new[v] = "I"
                    break
    return new

history = [dict(state)]
for _ in range(5):
    state = step(state, 1.0)
    history.append(dict(state))
assert [sum(s[v] == "I" for v in g) for s in history] == [1,1,1,1,1,0]
assert [sum(s[v] == "R" for v in g) for s in history] == [0,1,2,3,4,5]
assert all(len(s) == 5 for s in history)
print("SIR progression:", history)

从机制上讲，这个确定性实验只验证同步 SIR 的更新顺序与节点计数；它不验证任何真实疾病的传染率、免疫期或干预效果。

常见混淆与适用边界

传播概率 β 和传播率（连续时间中每单位时间的速率）不能直接相互替代；SIR 的 T 是全传染期的边传递概率。网络上平均路径短也不能保证大规模爆发，因为节点状态、接触概率和持续时间同样重要。跨社团连接会影响可达性，但大量重复暴露并不必然代表有效独立接触。

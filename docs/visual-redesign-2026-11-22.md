# 网络科学：28 章视觉推理与科学一致性设计审计

审校日期：2026-11-22。范围包括根目录全部 28 个 HTML、首页、对应 SVG 与确定性 V2 阅读器。

## 核心设计原则

每幅图必须解释一个可以指认的对象、一项会造成区别的机制，以及一个可复算的结果或明确边界。不要用主题色方框替代数学对象，也不能靠装饰性拓扑冒充真实实验。

每章阅读路径为：真实问题 → 独立 SVG 结构图 → 右侧三步核对 → 四个可跳转概念段落 → 已有深入图、MathML、代码、证据来源。保留原图和独立页面完整性。

视觉语义：蓝绿是可见结构或正常状态，琥珀是关键变化或需验证事实，珊瑚色表示风险、错误、未来信息。颜色不是唯一信号；有向边必须有真实箭头，未来边用虚线并附文字。

所有新增 SVG 均为 1100×510 的独立矢量文件，包含 title、desc 和 role=img，且不含远程资源。右侧三步说明是机制而不是宣传。手机端在图容器内滚动，不缩到无法辨认；容器有键盘焦点。图片下面必须有可理解的检验点。

## 修复记录

第 07 章最初的新直方图虽然保持8节点7边，却并非页面原始代码的实际度数分布。修订后的频数是 {0:2,1:2,2:2,3:1,5:1}，独立确认度数和14与二阶矩5.5；图、图注和可运行样本保持一致。不能只验证节点数和边数。

第 10 章必须将跨群体桥画成 C—D，不允许误画 C—F；本例二分模块度应为5/14。第 09 章用真实路径箭头标注有向链接，而不是仅靠上下文推测方向。第 24 章不能为了视觉完整虚构历史Karate数据的全部边集；第25章理论数组内存预算并不是实际程序峰值。

## 源文件与工程约定

- 正文单一来源：仓库根目录 01.html 到 28.html。
- SVG 源：assets/lessons/NN-visual.svg；V2 兼容资源 v2/apps/web/assets/lessons/NN-visual.svg，两份必须字节相同。
- 统一 CSS：v2/apps/web/site.css，负责 visual-storyboard、lesson-jump 和 diagram-viewport 的响应式样式。
- 六阶段首页学习地图：assets/learning-route.svg，配有六条实际可点击的 HTML 学习入口。
- 构建：根章节经 migrate_lessons.py 和 build_web.py 确定性同步到 V2，生成文件不允许独立修改。
- 核验：v2/tests/test_visual_storyboards.py 对 28 章 HTML、XML/ARIA、数学数值、双副本和内部目录检查；v2/tests/web/e2e.py 对 1440、768、390、360px 浏览器行为与截图做验收。
- 浏览器截图上传至 GitHub Actions Artifact，需与自动测试一同审阅。没有通过 CI 不能宣称“全部验收”。

在 v2 目录依次运行 Python 迁移快照检查、全套 unittest、Web生成检查、链接检查、Node 组件测试以及 Playwright Chromium E2E。详细命令见 README 的质量验收节。

本轮修复的是全站第一层视觉机制导览，不意味着每个复杂段落都已具备多帧演示。下一轮可继续为第 01–20 章的长段落制作逐状态图组，但新的学术结果必须先核实数据、公式与原始论文。
